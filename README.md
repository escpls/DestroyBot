# Единый Telegram-бот: заявки, жалобы и модерация

Бот объединяет обработку заявок на вступление, жалобы и команды модерации в одном `bot.py`. Для хранения данных используется один файл `data.json`.

## Файлы проекта

- `bot.py` — код бота.
- `requirements.txt` — зависимости Python.
- `.env.example` — пример необходимых переменных окружения без секретных значений.
- `.gitignore` — список файлов, которые не следует загружать в Git.
- `data.json` — создаётся автоматически при первом запуске; в архив не включён, поскольку содержит рабочие данные.

## Переменные окружения

Настройте следующие переменные в панели хостинга (например, Bothost → Variables):

- `BOT_TOKEN` — токен Telegram-бота.
- `OWNER_ID` — числовой Telegram ID владельца бота.
- `ADMIN_CHAT_ID` — ID административного чата.
- `MAIN_CHAT_ID` — ID основного чата.
- `DATA_FILE` — необязательно; путь к файлу данных, по умолчанию `data.json`.

Не публикуйте настоящий токен в GitHub и не добавляйте его в архив.

## Запуск локально

Требуется Python 3.10 или новее.

```bash
pip install -r requirements.txt
python bot.py
```

Если запускаете локально, можно создать файл `.env` на основе `.env.example`, но сам бот не загружает `.env` автоматически. Переменные нужно передать окружению или использовать подходящий загрузчик окружения. На Bothost достаточно заполнить Variables в панели управления.

## Развёртывание на Bothost

1. Загрузите файлы проекта в репозиторий GitHub и используйте ветку `main`.
2. В Bothost укажите репозиторий и ветку `main`.
3. Добавьте `BOT_TOKEN`, `OWNER_ID`, `ADMIN_CHAT_ID` и `MAIN_CHAT_ID` в разделе Variables.
4. Убедитесь, что команда установки зависимостей использует `pip install -r requirements.txt`, а команда запуска — `python bot.py`.
5. Запустите бота и проверьте логи.

**Важно:** храните резервную копию `data.json` отдельно. Не удаляйте этот файл при обновлении проекта, если хотите сохранить заявки, блокировки и историю. Убедитесь, что хостинг сохраняет файл между перезапусками; если файловая система временная, настройте постоянное хранилище.
